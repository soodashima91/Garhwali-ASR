Seeds before objectives: what actually improves low-resource Garhwali ASR?

At the corpus sizes typical of under-resourced dialects, a single training run can show a "gain" that is really just seed noise. We build the first reproducible multi-seed ASR benchmark for Garhwali on the official VAANI splits — and watch several plausible improvements dissolve once you test them properly.

Karamvir S. Batra, Prathamjyot Singh, Ashima Sood, Jasmeet Singh, Sahil Sharma · Thapar Institute & Ulster University

The targeted objective misses its target

The matra-weighted loss was designed specifically to reduce vowel-diacritic (matra) errors. It doesn't — the matra error rate is statistically unchanged (p=0.42). A single run might have shown a spurious drop.

The one thing that holds up: speed augmentation

Where fine-tuning acts · Appendix C

Fine-tuning repurposes the upper layers

A lightweight linear CTC probe reads each encoder layer. In the base model, decodable content peaks mid-network then degrades; fine-tuning reshapes exactly the top layers, where probe error falls all the way to near full-model performance. Lower WER is better.

What the errors are

Fine-grained drift, not gross mistakes

A functional categorisation of the remaining errors, reconciled across four independent LLMs. The system's errors are dominated by subtle orthographic and phonetic drift.
